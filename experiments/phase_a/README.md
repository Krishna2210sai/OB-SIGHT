# Phase A artefacts

Everything in this directory is generated by `python -m src.phase_a.run`. The
production preprocessing, saved models, API and frontend are not modified by
Phase A.

## Layout

| Path | Contents |
|---|---|
| `config.json` | Seed, window/sampling grids, quality thresholds, deep-learning budget and environment. |
| `dataset_manifest.json` | Dataset version, development record IDs, split counts and SHA-256 of `data/processed/dataset.csv`. |
| `folds.csv` | Fixed record-level 5-fold assignment for the 469 development records. |
| `data_quality/` | Per-record audit, aggregate summary, inclusion-policy sensitivity analysis and figures. |
| `window_experiments/` | 30/45/60-minute configurations: metadata, explicit exclusions, CV results and OOF predictions. |
| `sampling_experiments/` | 4/2/1/0.5 Hz configurations with anti-aliasing details and CV results. |
| `feature_selection/` | Six selection methods, per-fold selected features, stability tables and figures. |
| `deep_screening/` | Focused multimodal screening: metrics, training histories and OOF predictions. |
| `comparisons/` | Combined ranking, one-standard-error decision, ROC/PR and confusion figures. |
| `reports/` | Generated `PHASE_A_DATA_HANDLING_REPORT.md` (also copied to the repository root). |
| `logs/` | Execution log for each stage. |
| `cache/` | Rebuildable window tensors and feature tables. Ignored by git. |

## Reproduce

```bash
python -m src.phase_a.run --stage all
# or, without deep-learning screening:
python -m src.phase_a.run --stage all --no-dl
```

All comparisons use `split in {train, validation}` only. The 83 held-out test
records are never loaded. The decision rule is the one-standard-error rule:
configurations within one standard error of the best mean out-of-fold ROC-AUC
are treated as statistically indistinguishable, and the current production
configuration (30 min, 1 Hz, no feature selection) is preferred among them.

## Notes

- `cache/` is not committed; it can be rebuilt from the read-only dataset.
- Every exclusion of an insufficient-duration record is written to the
  configuration's `excluded_records.csv` and to its `config.json`.
- The feature selectors are fitted inside each training fold only.
- Deep-learning runs use 35 epochs, patience 8, batch size 32 and seed 42 for
  every configuration.
